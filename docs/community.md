# Communauté

Rejoignez le [groupe WhatsApp PyNativeX](https://chat.whatsapp.com/CXSjNzxzH8J0LxtZqMCjKh)
pour les échanges rapides.

Les décisions techniques doivent rester consultables : reformulez-les dans un ticket, une RFC ou
une ADR du dépôt. Le guide communautaire complet et le code de conduite sont à la racine du projet.

Les contributions sont ouvertes sur le SDK Python, le moteur C++, l’hôte Android Kotlin, le futur
hôte iOS, la documentation et les tests sur appareils d’entrée de gamme.
